# EOM Eurostat targeted extracts — 12 October 2026

These files were produced from the Eurostat data extracts uploaded in this conversation. They are not newly fetched live data. To keep the package manageable, each file retains all disaggregated rows for European reporting geographies relevant to the destination comparison and extracts recent year columns (2019–2025, where available). Dimension codes and source values are retained as-is.

`dataset_inventory.json` records input row counts, selected rows, dimensions, and years. Use official Eurostat metadata to decode dimension codes. Missing/suppressed values (often `:`) are not zero. Population projections are scenarios and must not be treated as observed outcomes. Migration statistics and demographic projections are contextual indicators, not evidence validating an individual Tech-MBA-to-sponsored-employment-to-settlement model.
